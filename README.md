## 🖥️ Preview

A neon-lit, terminal-aesthetic portfolio showcasing my work in blockchain, cryptography, data science, and full-stack development. Boot sequence intro, particle animations, 3D effects, and a fully responsive multi-page layout — no frameworks, just code.

---

## 📁 Structure

```
Portfolio/
├── index.html              # Landing page with boot sequence
├── html/
│   ├── about.html
│   ├── skills.html
│   ├── projects.html
│   ├── achievements.html
│   ├── education.html
│   └── contact.html
├── css/                    # Page-specific stylesheets
├── js/                     # Animations, particles, 3D engine
├── asset/                  # Images and media
└── vite.config.js          # Vite build config
```

---

## ✨ Features

- **Cyberpunk / neon dark theme** — custom color palette with glitch effects
- **Boot sequence intro** — animated terminal-style loading on first visit
- **Particle system** — dynamic background built in vanilla JS
- **3D engine elements** — depth and perspective effects without Three.js
- **Flip cards** — interactive project cards with hover reveal
- **Fully responsive** — mobile-first layout across all pages
- **Multi-page architecture** — clean separation of concerns

## 🚀 Run Locally

```bash

cd Portfolio
npm install
npm run dev
```
